### The Leaked Password Table

LedgerLine, the statement portal eight PurveX staff used for years, has been breached. The attackers posted the user table. LedgerLine changed how it stored passwords three times, so the dump holds four generations of the same accounts, each protected a different way.

Encoding, encryption and hashing all turn a password into something unreadable at a glance. They are not the same, and the difference decides what the attacker now holds:

- Encoding changes how data looks. Anyone can reverse it.
- Encryption hides data behind a key. Anyone with the key can reverse it.
- Hashing is one-way. Nobody can reverse it, but a weak password can still be guessed.

Your job is to find out exactly what this dump gives away before PurveX tells anyone to change a password. You will use CyberChef, the open-source toolkit analysts use to hash and decode data, and you will not log in to anything.

LedgerLine and every password in this lab are fictional.
