### Overview

This lesson builds the networking foundation the rest of this course depends on. TCP/IP addressing, the TCP three-way handshake, common ports and protocols, and how TLS layers encryption on top of an already-established connection. Every packet capture you will ever read is built from these five ideas stacked on top of one another, so it is worth understanding each layer before trying to read the whole stack at once.
