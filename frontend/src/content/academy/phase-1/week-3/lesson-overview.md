### Overview

This lesson builds the networking foundation the rest of this course depends on. It covers TCP/IP addressing, the TCP three-way handshake, common ports and protocols, and how TLS adds encryption to an established connection. Every packet capture you will read is built from these ideas stacked on top of one another. Understand each layer before you try to read the whole stack.
