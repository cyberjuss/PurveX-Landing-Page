### Overview

A SOC ships its work as a written detection query. This week turns everything already learned into one:

- The investigation mindset
- The baseline
- ATT&CK's shared vocabulary
- Last week's threshold

All of it becomes a line of code a student can read and defend. You'll learn KQL (Kusto Query Language), the language Microsoft Sentinel and Microsoft Defender both run detections in. You will also learn TRACE, a five-part method for writing a detection, built from this phase's own lessons rather than handed down as an arbitrary checklist.

By the end of this week you should be able to look at a real KQL detection and know what each part is doing and why, and build one yourself from a plain description of the behavior you want to catch.
