### Overview

In a SOC, the finished product of all this thinking is a written detection query. This week, you'll turn everything you've learned so far into one:

- The investigation mindset
- The baseline
- ATT&CK's shared vocabulary
- Last week's threshold

All of that ends up as code you can read and defend line by line. To write it, you'll learn KQL (Kusto Query Language), the language both Microsoft Sentinel and Microsoft Defender use for detections. Alongside it, you'll learn TRACE, a five-part method for writing a detection. Rather than being an arbitrary checklist, TRACE is built from the lessons you've already worked through in this phase.

By the end of the week, you should be able to look at a real KQL detection and explain what each part does and why. You should also be able to build one yourself, starting from a plain description of the behavior you want to catch.
