### Sources for this week's facts

- **The EICAR test file is a harmless file that antivirus products react to as if it were a virus, so you can test that detection works:** [EICAR: Download Anti Malware Testfile](https://www.eicar.org/download-anti-malware-testfile/)
- **VirusTotal checks a file against more than seventy antivirus engines and combines their verdicts:** [VirusTotal: How it works](https://docs.virustotal.com/docs/how-it-works)
- **`Get-MpThreatDetection` lists the active and past threats Defender detected on the computer:** [Microsoft Learn: Get-MpThreatDetection](https://learn.microsoft.com/en-us/powershell/module/defender/get-mpthreatdetection)
- **Sysmon records every new process as a Process Create event (Event ID 1) in its own Operational log:** [Microsoft Learn: Sysmon](https://learn.microsoft.com/en-us/sysinternals/downloads/sysmon)
